# Dictation clips (v1)

- SRC listen texts: Kokoro-82M, voice `bm_daniel`, en-GB, speed 1.0 (normal) and 0.8 (slow). License: Apache 2.0 (https://huggingface.co/hexgrad/Kokoro-82M).
- UBI Textaufnahme: Piper `de_DE-thorsten-medium`. Dataset: Thorsten Voice, CC0. See https://github.com/thorstenMueller/Thorsten-Voice and the Piper MODEL_CARD.
- Encoding: mono 22050 Hz, 48k MP3, loudness normalised to about −16 LUFS, true peak ≤ −1.5 dB.
- The spoken wording is an original practice set for this app, not a copy of official exam texts or third-party courses.
